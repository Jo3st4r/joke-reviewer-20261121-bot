A tiny deterministic program that writes one original one-line joke about working beside an AI coding agent to `/output/entry.txt`, for make.fun's "The joke the reviewer laughs at" bounty. An AI judge compares the entries two at a time, and the 20 best win rates share $35 in USDC.

## Run it

```sh
python3 main.py
```
